# Не потерять главное

Интерактивная шпаргалка к командной встрече с Альбертом Сафиным.

## Что умеет

- показывает дословные цитаты отдельно от пересказа;
- хранит отметки и заметки в браузере;
- позволяет добавлять собственные вопросы;
- создаёт общую комнату по ссылке и показывает курсоры участников через `Yjs` + `WebRTC`;
- экспортирует и импортирует итог встречи в JSON;
- работает как статический сайт на GitHub Pages.

## Запуск

```bash
npm install
npm run dev
```

## Проверка

```bash
npm test
npm run build
```

Совместный режим не требует сервера приложения: браузеры находят друг друга через публичный сигнальный сервер `y-webrtc`. Если сеть блокирует WebRTC, сайт продолжает работать локально; состояние можно передать снимком в ссылке или JSON-файлом.
