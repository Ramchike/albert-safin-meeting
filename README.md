# Не потерять главное

Одна общая интерактивная страница для выступления Альберта Сафина: готовая вводная, четыре главных запроса и полный банк уточняющих вопросов из командной расшифровки.

## Что умеет

- показывает дословные цитаты отдельно от пересказа;
- хранит отметки и заметки в браузере;
- позволяет добавлять собственные вопросы;
- открывает одну общую доску для всех посетителей и показывает курсоры участников через `Yjs` + MQTT over WebSocket;
- показывает заметки отдельными сообщениями с именами авторов;
- экспортирует и импортирует итог встречи в JSON;
- работает как статический сайт на GitHub Pages.

## Запуск

```bash
npm install
npm run dev
```

## Проверка

```bash
npm test
npm run build
```

GitHub Pages остаётся статическим размещением, а живая общая доска подключается к публичному демонстрационному MQTT-брокеру EMQX. Последнее общее состояние публикуется как retained message. Это прототипная публичная инфраструктура: не используйте заметки для секретных сведений. Если брокер недоступен, сайт продолжает работать с последним местным снимком; итог можно сохранить или восстановить через JSON.
